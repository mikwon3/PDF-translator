## PaperKo 1.8.6

빌드·배포 도구 정리 판입니다. **앱 기능·번역 동작은 1.8.5와 동일**하며, 새로 받을 기능 변화는 없습니다.

### 바뀐 점 (내부)

- 릴리스 스크립트가 발행 후 릴리스 저장소 README 의 "변경 이력"을 자동으로 갱신하도록 정리했습니다.
- 사용하지 않던 Windows MSIX 패키징 경로와 남아 있던 플레이스홀더(회사명) 흔적을 제거했습니다. 배포는
  기존과 같이 NSIS 설치본입니다.

### 내려받기

| 운영체제 | 파일 |
|---|---|
| macOS 12 이상 (Apple Silicon) | `PaperKo-1.8.6-arm64.dmg` |
| Windows 10 이상 x64 | `PaperKo-1.8.6-amd64-installer.exe` |

1.8.4 이상을 쓰고 있으면 앱이 시작할 때 이 판을 자동으로 확인해 받습니다. 처음 설치할 때는 개발자
서명이 없어 OS 경고가 뜨며, macOS 는 **시스템 설정 › 개인정보 보호 및 보안**에서 "그래도 열기",
Windows 는 "추가 정보 › 실행"을 누르면 됩니다. 각 파일의 SHA-256 은 아래 manifest 에 있습니다.
